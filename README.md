###__CollegeEvents-Website__###

INTRODUCTION :

Purpose of this website is to make it easy for college students who seek opportunities to participate in Hackathons, Club Events, Sports Events or in any other productive events which helps them in their career growth.

Current MVP features:
- User sign up and login with client-side and server-side validation
- Session-based authentication
- User profile update page
- Admin panel to view, edit, and delete users
- MySQL database integration through PHP and phpMyAdmin

Tech stack used : HTML, CSS, JavaScript, PHP, MySQL, Bootstrap

Setup:
1. Start Apache and MySQL in XAMPP/WAMP.
2. Create a database named college_events.
3. Import the SQL file from sql/schema.sql.
4. Open the project in your browser using the local server.
